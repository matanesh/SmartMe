# ערכת פיילוט: 5 הטיות שמשפיעות על ההחלטות שלנו

## למה הפרק הזה שווה האזנה

בחמש דקות מקבלים חמש שאלות קטנות שעוזרות לעצור לפני החלטה: האם מה שזכור באמת נפוץ, האם המספר הראשון עיגן אותנו, האם הניסוח שינה את הבחירה, האם חיפשנו רק אישור, והאם אנחנו ממשיכים רק מפני שכבר השקענו.

- **קהל:** אנשים סקרנים ללא רקע בפסיכולוגיה
- **שפה:** עברית טבעית ונגישה
- **משך רצוי לגרסת Notebook:** 4–5 דקות
- **מצב נוכחי:** קיים גם פרק קריינות עצמאי מאומת באורך 2:32 דקות; ערכת Notebook נשמרת כגרסה ידנית אופציונלית עם שני מגישים

## בדיוק שני צעדים ב-Gemini Notebook / NotebookLM

1. פתחו מחברת חדשה והוסיפו כמקור את הקובץ [`UPLOAD_TO_NOTEBOOK.md`](./UPLOAD_TO_NOTEBOOK.md). הקובץ כבר כולל את התקציר ואת קישורי המקורות המאומתים, כך שאין צורך לכתוב תסריט.
2. פתחו **Audio Overview / סקירת אודיו**, בחרו **Customize / התאמה אישית**, הדביקו את כל תוכן [`NOTEBOOK_PROMPT.txt`](./NOTEBOOK_PROMPT.txt), ולחצו **Generate / יצירה**. בסיום הורידו את קובץ האודיו לבדיקה לפני שילוב באתר.

## מה לבדוק אחרי ההורדה

לפני פרסום או חיבור לאפליקציה: לוודא שהקובץ אינו ריק, אורכו 2–5 דקות, העברית מובנת, שמות החוקרים נהגים באופן סביר, אין טענה שהטיה קובעת בוודאות מה אדם יעשה, והמקורות מוצגים כמחקר ולא כייעוץ אישי.
